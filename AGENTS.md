# Guía de trabajo para Codex — LIA

Leer [`.agents/skills/lia/SKILL.md`](.agents/skills/lia/SKILL.md) antes de abordar cambios de código, arquitectura, datos, automatización, seguridad, diseño o despliegue y cuando el usuario invoque «LIA». 
Respetar el README, las pruebas del repositorio y la continuidad del proyecto. 
Aplicar modelo Ejecutivo supervisado: no modificar producción, secretos, permisos críticos ni desplegar sin autorización.
No confundir código, pruebas aisladas y sistemas productivos. Entregar evidencia de cada prueba.
